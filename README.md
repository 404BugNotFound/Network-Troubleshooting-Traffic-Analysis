# Network-Troubleshooting-Traffic-Analysis

## Overview
This project demonstrates hands-on network troubleshooting and basic SOC-style traffic analysis on a Windows system using Wireshark and command-line tools.

## Tools Used
- Wireshark
- Command Prompt
- Windows OS

## Key Activities
- DNS resolution testing using nslookup
- ICMP connectivity checks using ping
- Route analysis using tracert
- Packet capture and filtering in Wireshark
- Identification of abnormal ICMP and TCP traffic patterns

## Security Focus
- Detection of repeated ICMP requests
- Identification of TCP SYN scan patterns
- Analysis of unknown destination IP traffic
